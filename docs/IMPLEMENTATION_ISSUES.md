# Implementation planning

Implementation tasks are maintained as live GitHub issues rather than copied
into this document:

- [open issues](https://github.com/ThalesMMS/go-dev/issues?q=is%3Aissue%20state%3Aopen)
- [Epic #899](https://github.com/ThalesMMS/go-dev/issues/899)
- [outcome and dependency roadmap](ROADMAP.md)

Each issue owns its scope, acceptance criteria, prerequisites, and validation.
Current library behavior belongs in [CAPABILITIES.md](CAPABILITIES.md) and its
linked package documentation.

Generated issue lists are not committed to versioned Markdown. They may be
created only as transient CI or release artifacts; the live GitHub query is the
authoritative state source.
